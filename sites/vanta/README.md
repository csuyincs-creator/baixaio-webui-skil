# SEVEN — FUTURE IS NOW.

响应式品牌概念官网。直接打开 `dist/index.html`，或在 dist 中启动静态服务器。

包含：系列筛选、商品详情、尺码选择、购物袋增加与移除、本地持久化、订阅体验、移动端菜单、信息弹窗、键盘焦点与减少动画设置支持。

这是展示原型。所有单品图片均为 AI 生成；没有真实库存、付款、配送或邮件发送服务。邮箱与购物袋只保存在当前浏览器。字体来自 Google Fonts，网络不可用时使用系统备用字体。

## 图片

四张图片使用内置 Imagegen 生成，保存在 `dist/assets/`，以 WebP 格式压缩用于网页。完整生成提示词见 `ASSET-PROMPTS.md`。
